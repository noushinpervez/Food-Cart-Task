# Food Cart Task

This project is a task submission for the Front-end Developer Intern position at Bangla Puzzle Limited. It showcases a basic e-commerce webpage with an "Add to Cart" functionality with a dynamic sidebar for item management. 

## Project Overview

The goal of this project is to implement a food item section where users can add items to a cart. A sidebar displays the added items with options to:
- Adjust the quantity of each item.
- Delete items from the cart.
- Prevent duplicate additions by disabling the "Add to Cart" button once an item is added.

The entire cart functionality is managed asynchronously using vanilla JavaScript and styled with Tailwind CSS for smooth interactions without any page reloads.

## Features

- **Add to Cart Functionality:** Adds selected food items to the cart.
- **Sidebar Management:** Displays added items with controls to adjust quantity and remove items.
- **Dynamic Button Behavior:** "Add to Cart" button disables once an item is added, preventing duplicates.
- **Price Calculation:** Calculates total prices dynamically as items are added, removed or modified.
- **Asynchronous JavaScript Operations:** JavaScript handles all interactions without page reloads.
- **Responsive Design:** The layout adjusts to different screen sizes, offering a consistent experience across devices.

## Technologies Used

- **HTML5**
- **JavaScript (Vanilla)**
- **Tailwind CSS**

## Setup Instructions

To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/noushinpervez/Food-Cart-Task.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Food-Cart-Task
   ```
3. Open the `index.html` file in your preferred web browser to view the project.

## Usage

1. **Add Items to Cart**: Click the "Add to Cart" button on any food item to add it to the cart.
2. **Adjust Quantity**: Use the controls in the sidebar to increase or decrease the quantity of items in the cart.
3. **Remove Items**: Click the delete button next to an item in the sidebar to remove it.
4. **Total Price Calculation**: The total price will automatically update as items are added, removed, or modified.
